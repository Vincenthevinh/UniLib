## How to Run & Verify
1. Reset and seed the database (`npm run db:reset` / seed script) and start PostgreSQL 16 + Express server (`src/server`).
2. Start the Vite dev server with `VITE_USE_MOCK=false`.
3. Sign in as a `Reader`, search/filter/sort in `SCR-05`, open a title in `SCR-06`, place a reservation via `SCR-09`, and verify it appears on `SCR-11`.
4. Test `401` handling (expired/invalid token triggers automatic logout and redirect to `/login`) and simulate network failure to verify error banner + `Retry` (`NFR-08`).
5. Run Lighthouse Accessibility audits in DevTools across 4 screens and save screenshots under `docs/design/a11y/lighthouse-*.png`.
