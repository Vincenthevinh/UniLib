# UniLib — Frontend Client (`src/client`)

Frontend client cho hệ thống **UniLib (University Library Management System)** xây dựng trên **React 18** và **Vite**, kiểm thử bằng **Vitest**.

## Hướng dẫn cài đặt & chạy
```bash
cd src/client
npm ci
npm run dev     # Khởi chạy Vite dev server tại http://localhost:5173
npm test        # Chạy test Vitest
npm run lint    # Kiểm tra lint
npm run build   # Build production bundle
```
