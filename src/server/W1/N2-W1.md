## Design decisions

- Uses `author` singular to match Quân's DBML / REST API, though SCR-03 label is Author(s).
- Title removal uses the backend's `DELETE /books/:id` semantics (deactivate); failures follow `TITLE_IN_USE`.
- Copy decommission calls `DELETE /copies/:id` and is blocked both by UI for Borrowed/Reserved and backend for historical circulation (`COPY_HAS_HISTORY`).
- Copy status is displayed read-only because circulation and reservation workflows own state transitions.
- Only three Staff/Admin screens are included. No payments, RFID hardware, email/SMS, e-books or other out-of-scope capabilities.
