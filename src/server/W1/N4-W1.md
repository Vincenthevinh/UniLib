## How to run after source integration
1. Use a branch based on current `main` after A1/N1/N2/N3 dependencies are merged or rebase carefully.
2. Set `VITE_USE_MOCK=false` and `VITE_API_BASE_URL=http://localhost:3000/api` in `src/client/.env.local` (port per actual server config).
3. Start PostgreSQL/Express according to repo's own `README.md` and Docker Compose instructions; run seed Q4. Check `/api/health` **only if** the implementation exposes that route (Quân contract mentions `GET /health` at base `/api`).
4. Log in as a seeded Librarian/Admin with real JWT. Test catalog/copies and F05 workflows; capture status responses and screenshots. Never put tokens/secrets in handoff.
5. Validate backend error codes against central map, inspect server logs and re-run tests.
