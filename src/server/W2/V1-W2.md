### 2.2 Kết quả Phân tích Bảng Gap 41 Endpoints
Quá trình rà soát đối chiếu giữa RTM PA3 §7, mã nguồn Express (`app.js`, `routes/`, `src/modules/`) và Frontend API Client (`endpoints.js`) cho kết quả:
* **Phía Backend:** Đã hiện thực đầy đủ **100% (41/41 endpoints)**, phân quyền RBAC đa vai trò được bao phủ bằng bộ test `tests/rbac.test.js` (165+ assertions).
* **Phát hiện 3 Gap lớn phía Frontend (`src/client/src/api/endpoints.js`):**
  1. **Gap 1 (Mượn sách - `loans.checkout`):** Frontend đang gọi `POST /api/circulation/checkout` và truyền `{ readerId, copyId }`. Trong khi Backend chuẩn hóa là `POST /api/loans/checkout` và nhận `{ readerId, barcode }` (hoặc fallback `copyId`).
  2. **Gap 2 (Trả sách - `loans.return`):** Frontend đang gọi `POST /api/circulation/return`. Backend chuẩn hóa là `POST /api/loans/return` với `{ barcode, conditionNotes?, condition? }`.
  3. **Gap 3 (Gia hạn - `loans.renew`):** Frontend đang gọi `POST /api/circulation/renew` với body `{ loanId }`. Backend chuẩn hóa là `POST /api/loans/:id/renew` (URL param `:id`, body rỗng).
  4. **Loại bỏ endpoint ảo:** Loại bỏ method tạm thời `api.circulation.eligibility` trong `endpoints.js`. Điều kiện mượn sách được kiểm tra qua cờ `restrictions` tại Dashboard bạn đọc hoặc bắt mã lỗi `422` từ server.
