## 1. Use Case Information

| Field | Specification |
|---|---|
| Use Case ID | UC-05 |
| Use Case Name | Search & Browse Book Catalog |
| Brief Description | Allows Readers and Librarians to search and browse Book Titles using catalog attributes, refine the results, and open a Book Title detail and availability view (UC-06). |
| Primary Actors | Reader, Librarian |
| Secondary Actors | None |
| Priority | Must |
| Related Feature | F04 — Book Search & Browse |
| Related Requirements | FR-F04-01, FR-F04-02, FR-F04-03, FR-F04-04 |
| Included Use Case | UC-06 — View Book Details & Copy Availability |
| Primary Screen | SCR-05 — Catalog Search & Browse Screen |
| Related Screen | SCR-06 — Book Title Detail & Availability Screen |
| Trigger | A Reader or Librarian opens the Catalog page to locate a Book Title or inspect its availability. |
| Preconditions | The UniLib web application and catalog service are accessible. The user has access to the Catalog interface. |
| Success Postconditions | Matching Book Titles and current availability information are displayed; when a user selects a Book Title, UC-06 presents its detail view. |
| Failure Postconditions | No catalog records are changed; the user receives an appropriate empty-result or error message. |

## 2. Main Success Flow — Search & Browse

1. The actor opens the Catalog interface (SCR-05).
2. The system displays the catalog search bar, Category selector, availability filter, sorting control, result cards, and pagination controls (SCR-05).
3. The actor enters a keyword corresponding to Title, Author, Category, or ISBN (SCR-05).
4. The actor submits the query using Search Catalog (SCR-05).
5. The system searches matching Book Title records using the specified attributes (FR-F04-01).
6. The system retrieves the current availability counts for each matching Book Title (FR-F04-03).
7. The system displays matching title cards with bibliographic information and Available Book Copy counts (SCR-05).
8. The system paginates the result set using the configured server-side page size (default 10 titles per page), according to FR-F04-04.
9. The actor selects View Details for a Book Title (SCR-05).
10. The system invokes UC-06 — View Book Details & Copy Availability and presents the selected title's metadata and copy availability on SCR-06.
11. The use case ends with the selected Book Title's detail view displayed.

## 3. Alternative Flows

### A1 — Browse without entering a keyword (at step 3)

1. The actor leaves the search field empty and uses the catalog browsing interface (SCR-05).
2. The system displays the available catalog titles with default pagination.
3. The actor may proceed to step 9 of the main flow.

### A2 — Filter or sort results (after step 7)

1. The actor selects a Category and/or availability filter, or chooses a Title/Publication Year sort order (SCR-05).
2. The system applies the selected filter/sort criteria (FR-F04-02).
3. The system refreshes the result cards and pagination on SCR-05.
4. The actor may select Clear Filters to return to the unfiltered catalog view.

### A3 — Navigate between result pages (at step 8)

1. The actor selects an available page number or Next/Previous on SCR-05.
2. The system retrieves the corresponding page of results (FR-F04-04).
3. The system displays the page without changing any catalog record.

### A4 — Included UC-06: View Book Details & Copy Availability (at step 10)

1. The system opens the selected Book Title's detail view (SCR-06).
2. The system displays its Title, Author(s), Category, ISBN, Publisher, and Publication Year.
3. The system calculates and displays Total, Available, Borrowed, and Reserved Book Copy counts (FR-F02-04).
4. The system displays the physical Book Copy list, including Copy ID, Shelf Location, and current Status (FR-F04-03).
5. If Available copies exist, the system indicates that the title is available for borrowing at the library; this screen does not perform checkout.
6. The actor may return to the Catalog (SCR-05).

## 4. Exception Flows

### E1 — No matching titles (at step 5)

1. The system finds no Book Titles matching the query and active filters.
2. The system displays an empty-result message on SCR-05.
3. The actor may modify the query or clear the filters.

### E2 — Catalog service unavailable (at steps 5–8)

1. The system cannot retrieve catalog results due to a service or network failure.
2. The system displays a user-friendly error on SCR-05, consistent with NFR-08.
3. The system does not report unverified availability data as current.

### E3 — Selected title is unavailable or has been removed (at step 10)

1. The system cannot retrieve the requested Book Title detail record.
2. The system displays an appropriate error on SCR-06 or returns the actor to SCR-05.
3. No catalog record is modified.

## 5. Business Rules

No new Business Rule is introduced by UC-05. Catalog viewing does not bypass BR-10 (role separation). The availability information is descriptive; reservation eligibility is evaluated separately under BR-05 in UC-10.
