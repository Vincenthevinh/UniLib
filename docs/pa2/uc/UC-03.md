## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC-03 |
| Use Case Name | Manage Book Catalog (CRUD Titles) |
| Description | Allows authorized Librarians to create, update, view, and conditionally delete or deactivate Book Title records while maintaining catalog consistency. |
| Primary Actor | Librarian |
| Priority | Must |
| Related Feature | F02 – Book Catalog Management |
| Related Requirements | FR-F02-01, FR-F02-02, FR-F02-03, FR-F02-04 |
| Related Business Rules | BR-09, BR-10 |
| Related NFRs | NFR-04, NFR-05 |
| Primary Screen | SCR-03 |
| Related Screen | SCR-06 – Book Title Detail & Availability |
| Trigger | A Librarian opens catalog management to create or maintain Book Title records. |

## 2. Preconditions

1. The Librarian has successfully authenticated.
2. The Librarian is authorized to manage Book Title records under BR-10.
3. The UniLib catalog service is available.

## 3. Postconditions

**Success:**

1. The requested Book Title operation is completed.
2. Book Title information is stored or updated consistently.
3. The catalog displays the resulting record or operation status.

**Failure:**

1. An invalid or unauthorized operation is rejected.
2. Existing valid catalog records remain unchanged by the rejected operation.

## 4. Main Success Flow – Create Book Title

| Step | Actor | Action |
|---|---|---|
| 1 | Librarian | Opens the Book Catalog Management interface (SCR-03). |
| 2 | System | Displays existing Book Title records and catalog management actions (SCR-03). |
| 3 | Librarian | Selects Add Book Title (SCR-03). |
| 4 | System | Displays the Book Title creation form (SCR-03). |
| 5 | Librarian | Enters ISBN, Title, Author(s), Category, Publisher, and Publication Year. |
| 6 | Librarian | Submits the completed form (SCR-03). |
| 7 | System | Validates required metadata and checks ISBN uniqueness (FR-F02-01). |
| 8 | System | Creates the Book Title record in the catalog. |
| 9 | System | Displays confirmation and the resulting Book Title record (SCR-03). |
| 10 | Librarian | Reviews the newly created Book Title information. |

## 5. Alternative Flows

### A1 – Update Book Title

**Entry point:** Main Flow, Step 2.

1. The Librarian selects an existing Book Title and chooses Edit (SCR-03).
2. The system displays the current metadata.
3. The Librarian updates the permitted fields.
4. The Librarian submits the changes.
5. The system validates the updated metadata.
6. The system saves the changes (FR-F02-02).
7. The system displays the updated Book Title information.

**Postcondition:** The catalog contains the updated Book Title metadata.

### A2 – View Book Title Details

**Entry point:** Main Flow, Step 2.

1. The Librarian selects a Book Title from the catalog list (SCR-03).
2. The system retrieves the corresponding bibliographic information.
3. The system calculates Total, Available, Borrowed, and Reserved Book Copy counts (FR-F02-04).
4. The system presents the record and availability information on SCR-06.

**Postcondition:** No catalog data is modified.

### A3 – Delete or Deactivate an Eligible Book Title

**Entry point:** Main Flow, Step 2.

1. The Librarian selects a Book Title and initiates its deletion or deactivation (SCR-03).
2. The system checks for associated physical Book Copies, active Loans, and pending Reservations.
3. The system confirms that all restrictions under FR-F02-03 and BR-09 are satisfied.
4. The system requests confirmation of the operation (SCR-03).
5. The Librarian confirms.
6. The system completes the permitted deletion or deactivation operation.
7. The system displays the operation result (SCR-03).

**Postcondition:** The Book Title is deleted or deactivated according to the approved catalog policy.

## 6. Exception Flows

### E1 – Duplicate ISBN

**Entry point:** Main Flow, Step 7.

1. The system detects that the submitted ISBN already exists in the catalog.
2. The system rejects creation of the duplicate Book Title.
3. The system displays a duplicate ISBN validation message on SCR-03.
4. The Librarian may correct the ISBN and resubmit.

**Postcondition:** No duplicate Book Title record is created.

### E2 – Book Title Has Associated Copies or Circulation Records

**Entry point:** Alternative Flow A3, Step 2.

1. The system identifies associated physical Book Copies, active Loans, or pending Reservations.
2. The system blocks the requested deletion or deactivation according to FR-F02-03 and BR-09.
3. The system displays the restriction reason on SCR-03.
4. The existing Book Title and its related records remain unchanged.

**Postcondition:** The restricted operation is rejected.

### E3 – Invalid or Incomplete Metadata

**Entry point:** Main Flow, Step 7, or Alternative Flow A1, Step 5.

1. The system detects missing or invalid required metadata.
2. The system refuses to save the invalid record.
3. The system identifies the affected input field on SCR-03.
4. The Librarian may correct the data and resubmit.

**Postcondition:** No invalid modification is stored.

## 7. Business Rules and NFR Constraints

- **BR-09:** Book Title deletion is restricted while physical Book Copies exist; Book Copies involved in active circulation cannot be removed.
- **BR-10:** Catalog management operations are restricted to authorized Librarians.
- **NFR-04:** Protected catalog-management API operations must enforce authorization.
- **NFR-05:** Catalog and inventory data operations must preserve database consistency, particularly when interacting with circulation records.

## 8. Related Acceptance Criteria

- AC-F02-01 – Create Book Title using a unique ISBN.
- AC-F02-02 – Reject duplicate ISBN.
- AC-F02-03 – Block deletion of a Book Title with registered physical copies.
