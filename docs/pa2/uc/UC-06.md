## 2. Preconditions

1. The UniLib Catalog service is accessible.
2. The actor can access the Catalog Search & Browse screen (SCR-05).
3. The selected Book Title exists in the Catalog.
4. The selected Book Title has a valid identifier.

## 3. Postconditions

### 3.1 Success Postconditions

1. The system displays the selected Book Title's bibliographic information.
2. The system displays aggregated Total, Available, Borrowed, and Reserved Book Copy counts.
3. The system displays associated Book Copy statuses and Shelf Locations.
4. No Book Title, Book Copy, Loan, or Reservation record is modified.

### 3.2 Failure Postconditions

1. The system displays an appropriate error message.
2. No Catalog or circulation data is modified.
3. The actor may return to the Catalog.

## 4. Main Success Flow

1. The actor opens the Catalog Search & Browse screen (SCR-05).
2. The system displays available Book Title records.
3. The actor selects View Details for a Book Title.
4. The system receives the selected Book Title identifier.
5. The system retrieves the corresponding Book Title metadata.
6. The system retrieves associated physical Book Copy records.
7. The system calculates aggregated Book Copy statistics:
   - Total Copies.
   - Available Copies.
   - Borrowed Copies.
   - Reserved Copies.
8. The system opens the Book Title Detail & Availability screen (SCR-06).
9. The system displays bibliographic information:
   - Title.
   - Author(s).
   - Category.
   - ISBN.
   - Publisher.
   - Publication Year.
10. The system displays the aggregated Book Copy counts.
11. The system displays Book Copy information:
   - Copy ID.
   - Shelf Location.
   - Current Status.
12. The actor reviews the information.

## 5. Alternative Flows

### A1 — Available Book Copies Exist

**Entry Point:** Main Flow, Step 7.

1. The system determines that at least one Book Copy has status Available.
2. The system displays the current Available Copies count.
3. The system displays the relevant Shelf Locations.
4. The actor may visit the circulation desk to request checkout.
5. Checkout is handled separately through UC-07 by an authorized Librarian.

### A2 — No Available Book Copies

**Entry Point:** Main Flow, Step 7.

1. The system determines that zero Book Copies have status Available.
2. The system displays Available Copies as zero.
3. The system indicates that the Book Title is unavailable for immediate checkout.
4. An eligible Reader may initiate UC-10 to request a Reservation, subject to BR-04, BR-05, and BR-06.
5. The actor may continue browsing the Catalog.

[TBD: Confirm the placement of the Reserve Book action on SCR-06.]

### A3 — Borrowed or Reserved Copies Exist

**Entry Point:** Main Flow, Step 10.

1. The system identifies Book Copies with status Borrowed or Reserved.
2. The system includes these copies in the appropriate aggregated counts.
3. The system displays their current statuses.
4. Borrowed and Reserved copies are excluded from Available Copies.
5. The actor continues viewing Book Title information.

### A4 — Damaged or Lost Book Copies Exist

**Entry Point:** Main Flow, Step 11.

1. The system identifies Book Copies recorded as Damaged or Lost.
2. The system excludes these copies from Available Copies.
3. The system displays their recorded statuses.
4. These copies are not eligible for checkout or Reservation allocation.
5. The actor continues viewing Book Title information.

This flow is consistent with the approved REV-08 damaged-return resolution.

### A5 — Return to Catalog

1. The actor chooses to return to the Catalog.
2. The system navigates to SCR-05.
3. The actor may continue searching or browsing Book Titles.

## 6. Exception Flows

### E1 — Book Title Not Found

**Entry Point:** Main Flow, Step 5.

1. The system cannot locate the selected Book Title.
2. The system displays a Book Title Not Found message.
3. The system does not display unrelated Book Title information.
4. The actor may return to SCR-05.
5. No Catalog data is modified.

### E2 — Catalog Service Failure

**Entry Point:** Main Flow, Step 5 or Step 6.

1. The Catalog service or network request fails.
2. The system displays an appropriate error notification.
3. The system does not present unverified availability data as current.
4. The actor may retry the request.
5. No Catalog or circulation data is modified.

### E3 — Availability Changes During Retrieval

**Entry Point:** Main Flow, Step 6 or Step 7.

1. Another authorized circulation operation changes a Book Copy status.
2. The system retrieves the most recently committed availability data when the detail view is refreshed.
3. The system recalculates the aggregated Book Copy counts.
4. The system displays the updated availability information.
5. Subsequent checkout or Reservation requests must independently validate eligibility.

## 7. Business Rules

| Rule ID | Application to UC-06 |
|---|---|
| BR-05 | Reservation eligibility depends on zero Available copies and no active Loan for the same Book Title. |
| BR-08 | Reserved Book Copies remain unavailable for general checkout during the 72-hour Pickup Window. |
| BR-10 | Readers have read-only Catalog access and cannot modify Book Title or Book Copy records through this use case. |

**Damaged Copy Handling:** According to REV-08, Damaged or Lost Book Copies must not be allocated to the FIFO Reservation queue. A pending Reservation remains Pending until an eligible Book Copy becomes available for allocation.
